# Human Finds a Way

一篇关于人工智能、人的价值、学习与共同未来的中文随笔。

## 阅读

- [文章源稿](./article.md)
- [PDF 版](./human-finds-a-way.pdf)

## 结构

1. 当机器开始比我们聪明
2. 我们在用衡量工具的方式，衡量自己
3. 当答案不再稀缺，我们为什么还要学习？
4. 与另一种智能共同演化

## 构建 PDF

需要 `uv`。构建脚本会在隔离环境中调用 Pandoc 与 WeasyPrint，将 Markdown 生成带现代文章样式的 PDF：
```bash
./build_pdf.sh
```
